I designed CompanyScope, a small financial-intelligence-style Next.js application where users browse, 
search, filter and shortlist fictional companies. It directly exercises React, strict TypeScript, Next.js App Router, 
Server/Client Components, testing, accessibility, Git and critical AI usage

User Stories:
As an analyst, I can see a responsive list of companies.
As an analyst, I can search by company name.
As an analyst, I can filter by sector and risk level.
As an analyst, I can open /companies/[id] to inspect one company.
As an analyst, I can add or remove a company from a watchlist.
As a keyboard user, I can operate every control and understand its label.
As a user, I receive meaningful empty, loading, not-found and error states.

Must Ship:
App Router and strict TypeScript
8–12 fictional companies
Catalogue, search and two filters
Dynamic company detail route
Local watchlist
Unit/integration tests
One Playwright E2E journey
GitHub Actions CI
README and decision notes
